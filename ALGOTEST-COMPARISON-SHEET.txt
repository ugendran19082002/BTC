  RESOLVED: AlgoTest CAN do the 15-30 band
   AlgoTest's Leg Builder has a "Premium Range" strike criteria: it selects
   strikes whose premium falls between a lower and an upper bound, and when
   more than one strike qualifies it takes the HIGHER premium for a Sell leg
   and the lower premium for a Buy leg.
   That is exactly what this reproduction does (it takes max(premium) inside
   the band for a short leg), so variant B is directly comparable.

   -> Set B as: Strike Criteria = Premium Range, lower 15, upper 30.

   RECOMMENDED: run A as "Premium Range 0 - 15" rather than "Premium <=".
   That puts A, B and C on the same criteria type and removes one possible
   source of mismatch. If A's number changes when you switch from
   "Premium <=" to "Premium Range 0-15", the two are not the same rule and
   that alone explains part of the gap.

   Also available if wanted later: "Closest Delta" and "Delta Range", which
   would let the delta variants from section R1 be tested on AlgoTest too.
